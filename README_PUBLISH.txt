FREE GITHUB PAGES STEPS
1. Sign in to GitHub and create a PUBLIC repository named cybersecurity-academy.
2. Upload ALL files in this folder to the repository root (not this folder itself).
3. Open Settings → Pages.
4. Select Deploy from a branch; choose branch main and folder /(root); click Save.
5. Wait for the Pages screen to show the public URL. It usually resembles https://YOUR-USERNAME.github.io/cybersecurity-academy/
